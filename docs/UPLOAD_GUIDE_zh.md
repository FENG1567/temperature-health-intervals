# 上传GitHub的文件范围

本仓库根目录内的文件已按复现用途整理。`code`、`scripts`、`tests`、`inputs`、`city_case`、`results`、`additional_analyses`、`paper`、`environment`、`.data_chunks`、`.github`及根目录说明/许可/引用/依赖/清单文件应随仓库一起上传。`.gitignore`规定的本地生成物除外。

需要上传的科学材料包括：实际执行代码、固定生成器快照、配置、去标识的聚合输入、固定设计数组、逐次正式模拟输出及同结局配对记录、期刊当前编号的补充CSV和PDF参照图。大因子缓存通过分块提供，不把超限NPZ或旧238MB压缩包直接加入Git。

补齐的工程材料包括：可移植运行入口、输入/输出目录隔离、依赖安装文件、缓存校验与恢复、主表及补充表重汇总、图件构建代码、少量种子回放检查、持续集成、文件SHA256清单、引用与许可说明、数据来源及复现边界文档。

不需要上传：DOCX/PDF正文、作者签字/投稿信、编辑审稿意见及整改报告、聊天记录、WPS脚本、文档页面预览、旧稿/备份、`.venv`、`__pycache__`、运行日志和重新生成的`outputs`。本轮只完成本地整理，没有上传、创建GitHub仓库或对外发布。

若使用网页上传，应保留`.github`和`.data_chunks`这些点开头目录。若使用Git，在本目录执行`git init`、`git add .`后可用`git status`检查待提交范围；GitHub仓库地址由实际创建后填入，不在此虚构。
