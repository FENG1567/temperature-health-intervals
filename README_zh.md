# 本项目的代码与数据复现

以英文 `README.md` 的命令为准。建议 Python 3.12，先建立虚拟环境并安装 `requirements.txt`，再运行：

```sh
python reproduce.py all
```

此命令包含文件校验、从逐次结果重汇总表格、重绘论文图和少量固定随机种子结局回放；不会悄悄启动完整24,000次测试。表格生成报告区分“实际重新汇总”与“复制数据字典/确定性来源表”，没有把复制冒充模型重算。

完整模拟或模型重跑使用 `python reproduce.py analysis --stage ... --formal`，具体阶段见英文说明。所有新结果写入 `outputs/`，归档正式结果作为比较基准保存。论文中Quasi与MVN回放重用原6000个日度结局，不是新增独立测试。

目录中的 `.data_chunks/` 是两个大于100MiB的可选缓存的分块，每块16MiB以内。可用 `python reproduce.py restore-cache` 校验并恢复；普通GitHub上传无需Git LFS。不要遗漏以点开头的目录。

复现从已提供的聚合输入开始。月度温度空间权重部分来源未留存，不能凭空补写；不声称从全部原始行政微观数据和温度网格重新完成上游处理。该边界与正文保持一致。

请将本目录整体作为GitHub仓库根目录。不要把“给编辑的”正文、Word文件、内部复审报告、旧压缩包、虚拟环境、输出缓存或其它项目备份一并上传。
